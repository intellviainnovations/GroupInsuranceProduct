# Specs

Requirements, domain rules and acceptance criteria. One file per feature or rule set, e.g. `group-policy-enrolment.md`.

Each spec has: purpose, actors, rules, edge cases, acceptance criteria (testable, numbered), open questions (Qn), source (insurer policy wording or business owner).

Insurance rules must be confirmed by a human domain expert against the insurer's policy documents before they are marked Accepted. The hospital-cash rule is pending (Q1) and must not be implemented until resolved.
